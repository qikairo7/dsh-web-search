# AGENTS.md — Rejected Agent Notes

These notes preserve a proposal that was considered and declined. Follow the [Agent Note rules](../README.md) and the [documentation standard](../../../docs/AGENTS.md).

- Use `Status: rejected — <one-line reason>` and keep the proposal-time sections, including `## Problem`, `## Proposal`, and `## Alternatives considered`.
- Keep the note only while its rationale prevents a plausible repeated mistake; otherwise delete it.
- Never turn a rejected note into an implemented note in place; write a new proposal and cross-link both.
