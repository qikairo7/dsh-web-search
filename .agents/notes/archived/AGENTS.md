# AGENTS.md — Archived Agent Notes

These notes are frozen history. Follow the [Agent Note rules](../README.md) and the [documentation standard](../../../docs/AGENTS.md).

- Archived notes keep `Status: implemented` and add `Archived: YYYY-MM-DD` immediately below it.
- Do not edit, translate, reformat, move, or delete an archived note.
- Do not treat an archived note as current behavior; link to it only as historical evidence.
- Archive only implemented notes whose decision is complete and whose rationale is unlikely to guide future work.
