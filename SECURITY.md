# Security policy

[中文](SECURITY.zh.md) / English

## Supported versions

Only the latest release gets security fixes. Pre-release versions get fixes on a best-effort basis.

## Reporting a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting: open the repository's **Security** tab, go to **Advisories**, and click **Report a vulnerability**. Do not open a public issue.

Include the affected version, the reproduction steps, and the impact. We aim to acknowledge a report within 7 days, then publish a fix or mitigation as soon as we can.

## Scope

This policy covers the plugin code in this repository. Report problems in [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), in a third-party search or fetch service, or in a dependency to that project. See [SAFETY.md](SAFETY.md) for the risk model.
