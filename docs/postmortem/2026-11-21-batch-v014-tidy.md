# 主检出 pull 删掉 REVIEW-LESSONS 与 .agents

## 时间线

- 10:04 PR #196 合并：REVIEW-LESSONS.md、REVIEW-LESSONS-archive.md、.agents/ 从 git 索引移除（本地保留），并加入 .gitignore。
- 随后主检出做 ff 同步，git pull 把这些本地化文件连同本地内容一起删除。
- 发现后从删除提交的父提交恢复：git show <删除提交>^:REVIEW-LESSONS.md > REVIEW-LESSONS.md。

## 影响

- 错题本本体（10 条 open 教训）与验收 skill 规程（.agents/）一度从磁盘消失。
- 靠 git show 从历史恢复，内容没丢；.gitignore 里的本地行（.local/ 等）也被 merge 冲掉，pull 后要补回。
- 潜在影响：没及时发现的话，后续评审与验收会丢历史教训和规程，新会话还会以为「本地文件未提供」。

## 根因

- 本地化文件在远端是删除提交：PR #196 把它们从公开仓库移除，主检出 pull 时按远端状态删掉本地副本。
- 同步流程缺备份步骤：收尾清单的主检出 ff 同步原先没有「本地文件先备份/恢复」动作，pull 直接覆盖工作区。

## 教训 → 规则化

- 本地化文件在远端是删除提交，主检出同步前要先备份，或记住恢复源命令 git show <删除提交>^:<path> > <path>。
  - 回流：已固化进 pr-merge 手册「本地维护文件双轨制」节和收尾清单的 ff 同步步骤；错题本经 REVIEW-LESSONS-inbox.md 预记（2026-11-21 整理链）。

> 历史注记：上文所引 `pr-merge` 手册「本地维护文件双轨制」节与收尾清单步骤，为事发时（2026-11-21）的流程命名；现行规则以 [docs/AGENTS.md](../AGENTS.md) 与 `docs/agents/` 为准。
