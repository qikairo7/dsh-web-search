# 升级到 0.13.0

面向已安装 0.12.x 的用户。变更全貌见 `../../CHANGELOG.md` 的 0.13.0 节；决策依据见对应 ADR。

## 无缝升级

- 直接更新安装即可：所有新配置字段都有默认值，默认行为与 0.12.x 一致（已有测试断言零变化）。
- 不需要新凭据、不需要改 cordis 配置。

## 新能力（默认已开，按需调整）

- **Bing 免 Key 搜索地板**（ADR-0011）：默认启用，位于免费池之后、付费尾之前；不需要 key。不想要：`bingEnabled: false`。自定义区域：`bingMarket`。
- **失败分类回退门控**：`fallbackFailureClasses` 默认六类全开（行为同旧版）；把 `invalid-response` 移出列表后，坏响应不再静默滑向下一家而是大声失败；置空数组 = 任何失败立即中止。

## 新 clone 需要一步

钩子目录不随 clone 自动生效，装完依赖后执行一次：

```sh
git config core.hooksPath .githooks
```

效果：每笔提交只跑秒级语法检查，push 前跑一次全量 `pnpm check`。

## 开发者可见的门禁变化

`pnpm check` 新增 provider 顺序与文档对账门（`scripts/check-order-sync.mjs`），文档门禁必需文件加入 `docs/pr-gate.md` 与 `AI-REVIEW-LESSONS.md`；`test/` 新增 Bing 地板与失败分类回退的覆盖。机械检查清单见 `../AGENTS.md`。
